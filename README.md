## 5. 기능별 테스트 및 완료 기준 (정상/예외 케이스)

| 기능 ID | 기능명 | 정상 상황 확인 결과 | 예외 상황 확인 결과 |
| :--- | :--- | :--- | :--- |
| F-01 | 대여 가능 수량 조회 | 지정한 날짜의 (보유 수량 - 대여 수량)이 정확히 계산되어 표에 출력됨 | 과거 날짜 선택 시 조회 차단 및 안내 메시지 표시 |

| F-04 | 대여 현황 조회 | 대여/반납 데이터 변경 사항이 실시간 표 형태로 갱신됨 | 데이터가 없는 경우 빈 데이터 안내 메시지 출력 |

## 6. 비기능 요구사항 (품질 및 정합성)

### 1. 데이터 정합성 및 실시간성 (Data Integrity & Real-time Update)
- 대여 신청 및 반납 수량 변경 시, pandas 데이터프레임 및 원본 CSV 파일에 즉시 반영되어 데이터 누락이나 수량 오차가 발생하지 않아야 한다.
- 대여/반납 처리 즉시 대여 현황 표(F-04) 및 날짜별 대여 가능 수량(F-01)의 계산 결과가 실시간으로 갱신되어야 한다.

### 2. 시스템 사용성 및 반응성 (Usability & Responsiveness)
- Streamlit 기반 화면 인터페이스는 대여/반납 현황을 직관적인 표 형태로 제공하여 사용자가 재고 상태를 3초 이내에 파악할 수 있어야 한다.
- 예외 상황(수량 초과, 날짜 오류 등) 발생 시 사용자에게 명확한 경고 메시지를 화면에 즉시 표시해야 한다.
