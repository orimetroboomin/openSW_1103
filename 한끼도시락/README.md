# 한끼도시락 주문 관리 — 실행 초안
관리자 전용, 단일 로컬 사용자용입니다. 실제 운영·다중 사용자 서비스가 아닙니다.

## 실행 (사용자 PC)
1. Python 가상환경 생성: `python -m venv .venv`
2. Windows: `.venv\Scripts\activate` / macOS·Linux: `source .venv/bin/activate`
3. `python -m pip install -r requirements.txt`
4. `python -m streamlit run app.py`
5. AI 사용 시 Ollama를 별도로 설치·실행하고 `ollama pull qwen3.5:2b-q4_K_M` 실행. 모델 제공 여부·라이선스·실행 메모리는 직접 확인합니다. 환경변수 OLLAMA_HOST·OLLAMA_MODEL로 변경 가능합니다. .env 자동 로딩은 구현하지 않았습니다.
6. 모델 연결 점검: `python smoke_test.py`
7. 단위 시험: `python -m unittest discover -s tests -v`

## 범위·차이
- 등록·수정·취소·집계·상태 변경 및 주문 맥락 AI 안내 구현 초안.
- 메뉴는 목록이 제공되지 않아 자유 입력. 사전 메뉴 목록은 추후 확정.
- S-01~S-06은 별도 페이지 대신 목록/등록/집계와 상세·수정·AI 패널로 묶었습니다.
- 등록 성공 후 선택 ID를 저장하지만 등록 메뉴를 유지합니다. 목록으로 이동하면 해당 주문이 선택됩니다.
- 날짜는 실행 PC의 로컬 달력 날짜. 신규 과거일·당일 주문 및 변경 수령일의 최소 준비기간은 정책 미확정으로 제한하지 않습니다.
- 발주 완료는 원문 상태명만 유지하며 준비 완료라고 단정하지 않습니다. 이후 변경 제한은 설계 가정입니다.
- CSV 원자적 교체로 저장 중 오류를 줄이나 동시 편집 잠금은 없습니다. 단일 사용자로만 실행하세요.
- AI는 CSV를 쓰지 않습니다. 답변은 오류가 있을 수 있으며 화면의 코드 판정이 기준입니다.
- 실사용자 인증·외부 알림·결제·장바구니·배송 입력 없음.
- UI 및 실제 Ollama 모델 연동은 아직 실행 검증하지 않았습니다. 개발노트 QA의 미실행 항목을 직접 확인하세요.
